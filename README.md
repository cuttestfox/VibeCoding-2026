# VibeCoding-2026
內容

分成主世界、下界、末地三個分頁，背景和地面會跟著世界切換：藍天草地、岩漿紅橘、紫黑星空。
收錄 39 種生物，名稱依中文 Minecraft Wiki 的繁體用語。
每種生物都有用方塊拼成的 3D 模型，可以拖曳旋轉、縮放。
右側特性欄和下方資訊卡列出生命值、傷害、行為、特徵、掉落物和生存小撇步。

互動玩法

生物會在場地裡自己行動：友好動物閒逛，敵對生物追擊或遠程攻擊。
你可以放食物引導動物，例如豬跟著胡蘿蔔走。
道具欄有鐵桶、剪刀、馬鞍，可以擠牛奶、剪羊毛、騎豬和馬。
苦力怕會靠近引爆，豬布林看你有沒有穿金裝決定攻不攻擊，界伏蚌的子彈會讓你飄起來。
被攻擊時右側的 10 顆紅心會逐顆消失，復活後回滿。
